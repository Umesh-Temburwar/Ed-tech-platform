# Security Policy

## Supported Versions

We actively provide security patches and dependency vulnerability updates for the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of our platform, user accounts, and database integrity seriously.

If you believe you have discovered a vulnerability, please **DO NOT** disclose it publicly via GitHub issues.

Instead, please email:
**umeshtemburwar2002@gmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce or a proof of concept (PoC).
- Any recommended remediations or patches.

We will acknowledge receipt within 48 hours and work with you to resolve the issue swiftly.
